# 📱 راهنمای تنظیم پیامک در پروداکشن

## ❌ اشتباه رایج

متغیرهای محیطی زیر در Railway **نیازی به تنظیم ندارند**:
```
KAVENEGAR_API_KEY=xxx
KAVENEGAR_SENDER=xxx
```

این متغیرها از کد قدیمی باقی مانده‌اند و **دیگر استفاده نمی‌شوند**.

---

## ✅ روش صحیح تنظیم پیامک

سیستم فعلی از **ملی‌پیامک (Melipayamak)** استفاده می‌کند و تنظیمات از **دیتابیس** خوانده می‌شود.

### روش 1: از پنل ادمین (توصیه می‌شود)

1. وارد پنل ادمین شوید
2. به بخش **تنظیمات** > **اعلان‌ها** بروید
3. اطلاعات زیر را وارد کنید:
   - **نام کاربری پنل ملی‌پیامک**
   - **رمز عبور پنل ملی‌پیامک**
   - **شماره فرستنده** (اختیاری)
4. ذخیره کنید

### روش 2: از اسکریپت

```bash
node scripts/set-sms-settings.js
```

این اسکریپت اطلاعات را از شما می‌گیرد و مستقیما در دیتابیس ذخیره می‌کند.

---

## 🔍 چطور اطلاعات پنل ملی‌پیامک را پیدا کنم؟

1. وارد پنل شوید: https://panel.payamak-panel.com
2. از بخش **وب‌سرویس** یا **API** اطلاعات زیر را کپی کنید:
   - نام کاربری (Username)
   - رمز عبور (Password)
3. از بخش **خطوط من** شماره فرستنده خود را بردارید

---

## 📋 خلاصه

| محل تنظیم | استفاده | دلیل |
|-----------|----------|------|
| Environment Variables (Railway) | ❌ KAVENEGAR_* | قدیمی و غیرفعال |
| Database (Settings Model) | ✅ smsUsername, smsPassword | روش فعلی |
| پنل ادمین | ✅ بخش تنظیمات > اعلان‌ها | بهترین روش |

## ❗ نکات مهم

1. **تنظیمات در دیتابیس ذخیره می‌شود** - نه در Environment Variables
2. **برای Production**: از پنل ادمین تنظیمات را وارد کنید
3. **شماره فرستنده** اختیاری است - اگر خالی باشد از نام کاربری استفاده می‌شود
4. **متغیرهای KAVENEGAR** را IGNORE کنید - نیازی به حذف آنها نیست، فقط استفاده نمی‌شوند

---

## 🆘 رفع مشکل

### پیامک ارسال نمی‌شود

1. بررسی کنید تنظیمات در دیتابیس ذخیره شده است
2. با اسکریپت standalone تست کنید (بالا)
3. لاگ‌های سرور را بررسی کنید
4. اعتبار حساب ملی‌پیامک را چک کنید

### خطای "تنظیمات پیامک ناقص است"

این یعنی `smsUsername` یا `smsPassword` در دیتابیس خالی است.
- از پنل ادمین یا اسکریپت `set-sms-settings.js` استفاده کنید
