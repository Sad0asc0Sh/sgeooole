---

## ❌ مشکل اصلی چی بود؟

شما فکر می‌کردید باید متغیرهای `KAVENEGAR_*` را در Railway پر کنید، اما:

- این متغیرها **قدیمی** هستند
- سیستم فعلی از **ملی‌پیامک** استفاده می‌کند
- تنظیمات از **دیتابیس** خوانده می‌شود، نه Environment Variables

---

## ✅ راه حل نهایی: پنل ادمین

### مراحل:

1. **وارد پنل ادمین شوید**
2. **بروید به: تنظیمات → اعلان‌ها**
3. **اطلاعات پنل ملی‌پیامک را وارد کنید:**
   - نام کاربری (Username)
   - رمز عبور (Password)  
   - شماره فرستنده (اختیاری)
4. **ذخیره کنید**

این تنظیمات در دیتابیس ذخیره می‌شود و برای **همه محیط‌ها** (local, staging, production) کار می‌کند.

---

## 📝 راه‌های دیگر

### از اسکریپت (اگر دسترسی به دیتابیس دارید):

```bash
node scripts/set-sms-settings.js
```

### تست پیامک:

```bash
# بدون نیاز به دیتابیس
node scripts/test-sms-standalone.js

# با دیتابیس
node scripts/test-sms-complete.js 09123456789
```
