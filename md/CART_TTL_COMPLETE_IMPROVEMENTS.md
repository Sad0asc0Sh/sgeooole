# سیستم کامل TTL سبد خرید - تمام بهبودها

## خلاصه کلی

این سند خلاصه‌ای از **تمام بهبودهای اعمال شده** به سیستم TTL (Time To Live) سبد خرید است که شامل دو بخش اصلی می‌شود:

1. **صفحه تنظیمات (Settings)** - برای پیکربندی رفتار سبد
2. **صفحه سبدهای رها شده (Abandoned Carts)** - برای مانیتورینگ و مدیریت

---

## 📋 بخش 1: صفحه تنظیمات (Settings)

### هدف
> "منطقی و قابل لمس کردن تنظیمات تا ادمین گیج نشود"

### بهبودهای کلیدی

#### 1. پیش‌نمایش زنده (Live Preview)
```
🎬 سناریو واقعی با ساعت‌های دقیق:
🕐 همین الان (14:30): کاربر محصول اضافه می‌کند
🔔 15:00: هشدار ارسال می‌شود
⏰ 15:30: سبد منقضی می‌شود
```

**فایل:** `admin/src/pages/settings/SettingsPage.jsx`

#### 2. مثال‌های عملی
```
⚡ 0.5 ساعت: محصولات محدود و پرفروش
⭐ 1-2 ساعت: حالت استاندارد (توصیه می‌شود)
📦 3-6 ساعت: خریدهای سنگین‌تر
🏢 24-72 ساعت: فروشگاه‌های B2B
```

#### 3. Validation هوشمند
```javascript
// جلوگیری از تنظیمات نامنطقی
if (warningMinutes >= cartTTLMinutes) {
  Error: "زمان هشدار نمی‌تواند بیشتر از مهلت سبد باشد!"
}
```

#### 4. حالت‌های مختلف با توضیحات واضح
- سبد ماندگار (بدون انقضا)
- سبد با مهلت (بدون هشدار)
- سبد با مهلت + هشدار

**مستندات کامل:** `CART_SYSTEM_IMPROVEMENTS.md`

## 📊 بخش 2: صفحه سبدهای رها شده (Abandoned Carts)

### هدف
> "نمایش زنده و قابل لمس زمان باقیمانده تا انقضای هر سبد"

### بهبودهای کلیدی

#### 1. ستون Countdown با Progress Bar
```
🟢 Tag سبز + Progress: بیش از 30 دقیقه (عادی)
🟠 Tag نارنجی + Progress: 15-30 دقیقه (متوسط)
🔴 Tag قرمز + Progress: کمتر از 15 دقیقه (فوری!)
```

**فایل:** `admin/src/pages/orders/AbandonedCartsPage.jsx`

#### 2. آیکون‌های هوشمند
```
🕐 ClockCircleOutlined: حالت عادی
⚠️  WarningOutlined: هشدار متوسط
🔥 FireOutlined: فوری!
```

#### 3. Auto-refresh هر 1 دقیقه
```javascript
useEffect(() => {
  const interval = setInterval(() => {
    fetchAbandonedCarts()
  }, 60000)
  return () => clearInterval(interval)
}, [])
```

#### 4. Modal جزئیات با بخش انقضا
```
📋 بخش "وضعیت انقضای سبد":
- Progress Bar بزرگ با رنگ‌بندی
- زمان دقیق آخرین به‌روزرسانی و انقضا
- Alert قرمز برای سبدهای فوری
- پیشنهاد ارسال یادآوری
```

#### 5. نشانگر Real-time
```
🕐 آخرین به‌روزرسانی: 14:35:22
• به‌روزرسانی خودکار هر 1 دقیقه
```

**مستندات کامل:** `CART_COUNTDOWN_IMPROVEMENTS.md`

## 🎯 جریان کامل کار (Workflow)

### گام 1: ادمین تنظیمات را انجام می‌دهد
```
📍 مکان: Settings > سبد خرید

1. ادمین به صفحه تنظیمات می‌رود
2. پیش‌نمایش زنده را می‌بیند که دقیقاً چه اتفاقی می‌افتد
3. تنظیمات را بر اساس نوع کسب‌وکار انتخاب می‌کند:
   - فروش فلش: 30 دقیقه + هشدار 15 دقیقه
   - استاندارد: 1-2 ساعت + هشدار 30 دقیقه
   - B2B: سبد ماندگار
4. ذخیره می‌کند (با validation هوشمند)
```

### گام 2: کاربران محصول به سبد اضافه می‌کنند
```
🛒 Frontend:
- کاربر محصول به سبد اضافه می‌کند
- expiresAt محاسبه می‌شود (updatedAt + TTL)
- Timer شروع می‌شود
```

### گام 3: ادمین سبدهای رها شده را مانیتور می‌کند
```
📍 مکان: Orders > سبدهای رها شده

1. ادمین لیست سبدها را می‌بیند
2. برای هر سبد می‌بیند:
   ✅ چند دقیقه تا انقضا مانده
   ✅ Progress Bar بصری
   ✅ رنگ فوریت (سبز/نارنجی/قرمز)
3. صفحه هر 1 دقیقه خودکار refresh می‌شود
4. سبدهای فوری با آیکون 🔥 قرمز مشخص می‌شوند
```

### گام 4: ادمین اقدام می‌کند
```
برای سبد فوری (🔥 قرمز):
1. کلیک روی "جزئیات"
2. دیدن Alert قرمز: "این سبد به زودی منقضی می‌شود!"
3. ارسال یادآوری فوری (ایمیل + پیامک)

برای سبد متوسط (⚠️  نارنجی):
1. ارسال یادآوری ایمیل
2. پیگیری در چند دقیقه آینده

برای سبد عادی (🕐 سبز):
1. مانیتور کردن
2. صبر تا نزدیک انقضا شود
```

### گام 5: سیستم خودکار کار می‌کند
```
🤖 Backend Cron Jobs:

هشدار خودکار:
- اگر expiryWarningEnabled: true
- و expiryWarningSent: false
- و زمان رسیده → ارسال هشدار به کاربر

پاکسازی خودکار:
- اگر permanentCart: false
- و expiresAt < الان → حذف سبد
```

## 🧪 تست کامل سیستم

### مرحله 1: تنظیمات را پیکربندی کن
```
1. برو به Settings > سبد خرید
2. مهلت را 1 ساعت تنظیم کن
3. هشدار را 30 دقیقه قبل فعال کن
4. پیش‌نمایش را بررسی کن:
   ✓ باید ساعت دقیق نمایش بدهد
   ✓ باید سناریو کامل نشان بدهد
5. ذخیره کن
```

### مرحله 2: سبد ایجاد کن (از Frontend)
```
1. به عنوان کاربر وارد شو
2. محصولی به سبد اضافه کن
3. سبد را رها کن (checkout نکن)
```

### مرحله 3: سبد را مانیتور کن (Admin)
```
1. برو به Orders > سبدهای رها شده
2. باید سبد را ببینی با:
   ✓ Tag سبز (اگر بیش از 30 دقیقه مانده)
   ✓ Progress Bar سبز
   ✓ زمان دقیق باقیمانده
3. 1 دقیقه صبر کن:
   ✓ باید خودکار refresh شود
   ✓ countdown آپدیت شود
```

### مرحله 4: تست فوریت
```
1. صبر کن تا کمتر از 30 دقیقه بماند:
   ✓ Tag نارنجی با ⚠️  باید نمایش داده شود
2. صبر کن تا کمتر از 15 دقیقه بماند:
   ✓ Tag قرمز با 🔥 باید نمایش داده شود
3. کلیک روی "جزئیات":
   ✓ Alert قرمز باید ببینی
   ✓ پیشنهاد ارسال یادآوری
```

### مرحله 5: تست یادآوری
```
1. در Modal جزئیات، "یادآوری ایمیل" بزن
2. Check کن که ایمیل ارسال شده
3. expiryWarningSent: true شود
```

### مرحله 6: تست انقضا
```
1. صبر کن تا سبد منقضی شود یا دستی پاکسازی کن
2. سبد باید:
   ✓ Tag "منقضی شده" نشان بدهد
   ✓ Progress 100% قرمز
```

## 💡 بهترین تمرین‌ها (Best Practices)

### برای فروشگاه‌های مختلف

#### فروشگاه لباس آنلاین
```
⏰ مهلت: 2 ساعت
🔔 هشدار: 30 دقیقه قبل
🔒 ماندگار: خاموش

دلیل:
- تصمیم‌گیری سریع
- موجودی محدود
- رقابت بالا
```

#### فروشگاه B2B صنعتی
```
🔒 ماندگار: روشن
(بقیه تنظیمات غیرفعال)

دلیل:
- سفارشات بزرگ
- تصویب چند نفره
- زمان تصمیم طولانی
```

#### فروش فلش
```
⏰ مهلت: 30 دقیقه
🔔 هشدار: 15 دقیقه قبل
🔒 ماندگار: خاموش

دلیل:
- موجودی بسیار محدود
- تقاضای بالا
- فشار زمانی
```

#### فروشگاه کتاب دیجیتال
```
⏰ مهلت: 24 ساعت
🔔 هشدار: خاموش
🔒 ماندگار: خاموش

دلیل:
- موجودی نامحدود
- زمان کافی برای تصمیم
- بدون نیاز به عجله
```

## 🎉 نتیجه‌گیری

با این بهبودها، سیستم TTL سبد خرید به یک **سیستم کامل، زنده و قابل لمس** تبدیل شده است:

### ادمین می‌تواند:
✅ تنظیمات را با **اطمینان کامل** انجام دهد (پیش‌نمایش زنده)
✅ سبدهای رها شده را **real-time** مانیتور کند (auto-refresh)
✅ سبدهای فوری را **فوراً تشخیص** دهد (رنگ‌بندی هوشمند)
✅ **به موقع اقدام** کند (Alert ها و پیشنهادها)
✅ **درک روشن** از وضعیت هر سبد داشته باشد (Progress Bar بصری)

### کاربران:
✅ هشدار **به موقع** دریافت می‌کنند (قبل از انقضا)
✅ فرصت **دوم برای خرید** دارند (یادآوری)
✅ تجربه **بهتر و منطقی‌تر** (زمان مشخص)

### کسب‌وکار:
✅ کاهش سبدهای رها شده با **یادآوری هوشمند**
✅ افزایش تبدیل با **پیگیری به موقع**
✅ مدیریت موجودی **بهینه** (سبدهای منقضی پاک می‌شوند)
