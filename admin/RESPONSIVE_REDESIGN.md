# 📱 ریسپانسیو‌سازی و بازطراحی پنل مدیریت

تاریخ: ۱۴۰۴/۰۶/۰۱ — بهینه‌سازی کامل برای موبایل (ابعاد ۳۲۰px تا دسکتاپ)

## ✨ تغییرات اعمال‌شده

### 1. سیستم طراحی سراسری
- **فونت وزیرمتن (Vazirmatn)** از CDN در `index.html` + fallback به IRANSans
- **تم حرفه‌ای antd** در `src/main.jsx`:
  - پالت رنگی Indigo جدید (`#4f46e5`) با رنگ‌های success/warning/error استاندارد
  - شعاع گردی بیشتر (`borderRadius: 10`) و سایه‌های لطیف
  - استایل اختصاصی Menu تیره، Table، Button، Modal و Pagination
- **CSS سراسری ریسپانسیو** در `src/index.css`:
  - جدول‌های عریض به‌صورت خودکار اسکرول افقی می‌گیرند (pagination ثابت می‌ماند)
  - مودال‌ها هرگز از عرض صفحه بیرون نمی‌زنند (`max-width: calc(100vw - 24px)`)
  - Drawer حداکثر `92vw`
  - کلاس‌های کمکی `.page-header` و `.filter-bar` برای هدر/فیلتر صفحات
  - سلول‌های جدول با `word-break` امن برای متن‌های طولانی

### 2. MainLayout جدید (`components/layout/MainLayout.*`)
- سایدبار تیره با گرادیان Slate و لوگوی گرادیانی Indigo→Violet
- هدر شیشه‌ای (backdrop-blur) با دکمه‌های آیکونی ۳۸×۳۸
- نام کاربر با ellipsis؛ روی موبایل فقط آواتار
- Drawer موبایل: هدر برندشده + دکمه بستن + فوتر پروفایل/خروج
- بسته‌شدن خودکار Drawer هنگام بزرگ‌شدن صفحه (هوک `useIsMobile`)
- پشتیبانی `safe-area-inset` برای iPhone

### 3. داشبورد (`pages/Dashboard.jsx`)
- کارت آماری سفارشی `StatCard` با آیکون رنگی (سبز/نیلی/کهربایی/آبی)
- نمایش درصد رشد فروش با فلش ↑↓
- نمودار فروش با رنگ برند و محورهای بهینه
- لیست موجودی کم با truncate متن طولانی

### 4. صفحات احراز هویت
- کارت ورود fluid: `width: '100%', maxWidth: 420` + گرادیان برند
- `minHeight: 100dvh` برای مرورگرهای موبایل
- رنگ لینک‌ها هماهنگ با تم جدید

### 5. اصلاحات انبوه صفحات (۲۵+ صفحه)
- **۲۲ جدول**: افزودن `scroll={{ x: 'max-content' }}`
- **هدر صفحات**: `flexWrap: 'wrap'` + `gap: 12`
- **فیلترها**: همه عرض‌های ثابت `maxWidth: '100%'` گرفتند

## 🔧 اسکریپت‌های کمکی (`admin/scripts/`)
- `add-table-scroll.mjs` — افزودن scroll به جدول‌های فاقد آن
- `responsive-batch.mjs` — اصلاح انبوه هدرها و عرض‌های ثابت
- `polish-auth-pages.mjs` — هماهنگ‌سازی صفحات auth با تم جدید

> این اسکریپت‌ها UTF-8 را حفظ می‌کنند؛ **هرگز** برای ویرایش این فایل‌ها از PowerShell با Set-Content بدون `-Encoding UTF8` استفاده نکنید (متن فارسی خراب می‌شود).

## 📏 نقاط شکست (Breakpoints)
| عرض | رفتار |
|---|---|
| `≥992px` | سایدبار ثابت + دکمه collapse |
| `<992px` | سایدبار مخفی + Drawer همبرگری |
| `<768px` | جدول compact، فیلترهای دوستونه |
| `<576px` | هدر ۵۶px، فقط آواتار کاربر، فیلتر تک‌ستونه |
